# Data

The datasets are not included in this repository. Place the original UNSW-NB15 and CIC-IDS2017
CSV files in `data/raw/UNSW_NB15/` and `data/raw/CIC_IDS2017/` (sources and file names are listed
in the main README). `scripts/preprocess.py` writes the cleaned train/test splits to
`data/processed/`. Both folders are ignored by Git.
